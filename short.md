### Aging as an evolutionary advantage

Humans, throughout our lives, gather experience, and the older the man, the wiser he becomes. So these older men will have a much better survival and procreative advantage. If there is no aging and slowing down of the old animal, future generations will be less diverse. This homogeneity makes the whole species an easy target for a sweeping disease. The longer the time, the higher the risk. 


So you can see, taking the advantage away brings back the balance and gives the species the strength via diversity.

### Dataset drift detection is a silly idea
The whole point of model based machine learning, or modelling as a method of understanding the world, is that your model can generalize. 
From a practical point of view, a generalized model can perform well on unseen (even drifted) data.
From an understanding point of view, a generalized model encapsulates how man thinks the world works.
Focus on making your model generalize well.



### Writing code that's breakable with tests
Taking the idea of modern scientific discovery by Karl Popper, a programmer should write code that's breakable in tests.
This is crucial for production grade code, where we absolutely need to know the boundary of the logic of the code and how it can break.

### Value of a test set
The more you use a test set, the less valuable it becomes. In some cases, we can measure this value by something like information gain i.e. how much information you have gained (in bits) from modifying your model using your test set. As a result, the best test set is only used once.
