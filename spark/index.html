Spark: speech to text tiếng Việt

Giữ phím fn rồi nói, thả ra là Spark paste text vào ô đang focus. Dùng được trong Cursor, VS Code, Terminal, Slack và mọi app khác.

$ curl -fsSL https://vuongnm.github.io/spark/install.sh | bash

Chạy lệnh trên trong Terminal, hoặc tải file .dmg. Apple Silicon, 133 MB, miễn phí, open source (MIT). Có bản Windows beta.

  • ~0,1 sSTT / 5 s audio
  • ~1 sthả phím → có chữ
  • 0 byteaudio rời máy

Giữ phím này để nói thử

Cách dùng

  1. Giữ fn rồi nói

    Một overlay nhỏ hiện ở cạnh dưới màn hình, hiển thị transcript real-time trong lúc bạn nói.

  2. Thả phím

    Khoảng 1 giây sau, text đã xử lý được paste vào ô đang focus, trong bất kỳ app nào.

  3. Hands-free

    Double-tap fn để nói mà không cần giữ phím, nhấn fn lần nữa để dừng.

Vì sao mình làm Spark

Lúc làm việc mình hay nói nửa Việt nửa Anh, kiểu "report toàn bộ bằng tiếng Việt". Model speech-to-text tiếng Việt nghe những câu như vậy ra chữ lung tung, sửa lại còn mất công hơn tự gõ.

Khi app đang focus là Cursor, VS Code hay Terminal, Spark giữ nguyên tên file, tên function và command, ví dụ nói "index chấm ts" sẽ ra index.ts. Tên project hay tên người thì thêm vào mục Từ điển (dictionary) trong app, Spark sẽ dùng chúng làm hotwords cho STT và để viết cho đúng.

Cài đặt

Terminal
$ curl -fsSL https://vuongnm.github.io/spark/install.sh | bash

Mở Terminal và chạy lệnh bên cạnh. Script tải release mới nhất từ GitHub Releases, copy Spark.app vào /Applications rồi mở app. Muốn update thì chạy lại lệnh này. Nên đọc script trước khi chạy.

Apple Silicon (M1 trở lên). Nếu tải bằng browser thì dùng file .dmg rồi kéo Spark vào Applications. Spark chưa được sign bằng Developer ID và notarize với Apple (cần Apple Developer Program, 99 USD/năm), nên lần đầu mở Gatekeeper sẽ chặn. Vào System Settings → Privacy & Security, bấm “Open Anyway”, hoặc xoá quarantine attribute:

xattr -dr com.apple.quarantine /Applications/Spark.app

Mở PowerShell và chạy lệnh bên cạnh (Windows 10, 11). Script tải bản cài mới nhất, cài cho user hiện tại, không cần quyền admin, rồi mở Spark. Giữ Right Ctrl để nói.

Bản Windows được build bằng CI nhưng chưa test kỹ trên máy thật, gặp lỗi thì mở issue trên GitHub giúp mình nhé. Hoặc tải file .exe.

Stack: Electron, React, TypeScript, sherpa-onnx, node-llama-cpp. License MIT. Phím fn trên macOS cần Xcode Command Line Tools để build helper Swift.

Lần đầu mở

Spark mở một hướng dẫn ngắn. Nó tải model STT (khoảng 80 MB), xin các permission dưới đây, rồi cho bạn giữ fn đọc thử ba câu mẫu để xem Spark viết lại thế nào. Muốn xem lại thì vào Cài đặt → Chung.

  • Microphone, để thu âm trong lúc bạn giữ phím.
  • Accessibility, để bắt phím fn và gửi lệnh paste (⌘V).
  • Input Monitoring, nếu macOS hỏi. Spark chỉ đọc phím fn, không log các phím khác.

Nếu nhấn fn mà emoji picker hiện lên, vào System Settings → Keyboard và đặt “Press 🌐 key to” thành “Do Nothing”.

Muốn có LLM cleanup thì tải Gemma 4 hoặc nhập Anthropic API key ngay trong hướng dẫn, hoặc sau này trong Cài đặt.

Uninstall

Xoá app và toàn bộ data (settings, history, models):

rm -rf /Applications/Spark.app ~/Library/Application\ Support/Spark

Gỡ Spark trong Settings → Apps. Data nằm ở %APPDATA%\Spark, xoá thư mục này nếu muốn dọn hết.

FAQ

Spark có gửi audio đi đâu không?

Không. Speech-to-text chạy hoàn toàn on-device. Nếu bạn chọn Claude để cleanup thì Spark chỉ gửi transcript (text, không có audio) tới Anthropic API bằng key của bạn. History chỉ lưu local và xoá được trong app.

Sao macOS chặn file .dmg?

Để Gatekeeper cho mở thẳng, app cần được sign bằng Developer ID và notarize qua Apple Developer Program (99 USD/năm). Spark chưa làm bước này. Source code public nên bạn có thể đọc hoặc tự build.

Sao cài bằng curl lại không bị chặn?

Browser gắn quarantine attribute (com.apple.quarantine) cho file tải về, và Gatekeeper chỉ kiểm tra file có attribute này. curl không gắn attribute đó, nên đọc script trước khi chạy.

Có cần mạng không?

Chỉ cần lúc tải model lần đầu và khi dùng Claude API. Dùng Gemma thì Spark chạy offline hoàn toàn.

Có mất phí không?

Spark miễn phí. Nếu dùng Claude thì Anthropic tính phí API theo key của bạn.

Yêu cầu phần cứng?

Mọi Mac Apple Silicon đều chạy được. Gemma 4 dùng thêm khoảng 2 GB RAM, nên máy 8 GB thì dùng Claude sẽ nhẹ hơn.
