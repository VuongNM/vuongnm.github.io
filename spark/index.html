spark: speech to text tiếng việt cho dân Coding

Nói tiếng Việt, chen tiếng Anh thoải mái.

Giữ phím fn rồi nói, thả ra là Spark gõ chữ vào chỗ con trỏ. Dùng được trong Cursor, VS Code, Terminal, Slack và các app khác.

$ curl -fsSL https://vuongnm.github.io/spark/install.sh | bash

Chạy lệnh trên trong Terminal, hoặc tải file .dmg. Mac chip Apple, 133 MB, miễn phí, mã nguồn mở. Có bản Windows thử nghiệm.

Cách dùng

  1. Giữ fn rồi nói

    Một bong bóng nhỏ hiện ở dưới màn hình, chữ chạy theo lời bạn nói.

  2. Thả phím

    Khoảng một giây sau, câu đã sửa được dán vào chỗ con trỏ, app nào cũng được.

  3. Nói dài thì nhấn hai lần

    Nhấn fn hai lần để nói mà không cần giữ phím, nhấn thêm lần nữa để dừng.

Vì sao mình làm Spark

Lúc làm việc mình hay nói nửa Việt nửa Anh, kiểu "report toàn bộ bằng tiếng Việt". Bộ nhận giọng tiếng Việt nghe những câu như vậy thành chữ lung tung, "report" ra "lừa đảo", "deploy" ra "đi phôi", sửa lại còn mất công hơn tự gõ.

Spark dùng hai mô hình nhận giọng chạy ngay trên máy. Mô hình tiếng Việt (Zipformer) đọc 5 giây nói trong khoảng 0,1 giây, còn một mô hình tiếng Anh nhỏ (Moonshine) nghe song song để bắt các từ như commit, merge, endpoint. Sau đó Gemma 4 chạy trên máy, hoặc Claude nếu bạn có khoá, viết lại thành câu hoàn chỉnh, có dấu câu và viết đúng các từ tiếng Anh.

Nếu bạn đang gõ trong Cursor, VS Code hay Terminal, Spark giữ nguyên tên file và tên hàm, ví dụ nói "index chấm ts" sẽ ra index.ts. Tên dự án hay tên đồng nghiệp thì bạn thêm vào Từ điển để Spark viết cho đúng.

Spark luôn so câu viết lại với lời gốc, nếu mô hình tự thêm ý hoặc đổi con số thì kết quả đó bị bỏ. Âm thanh không ra khỏi máy, và nếu dùng Gemma thì không cần mạng.

Cài đặt

macOSMac chip Apple (M1 trở lên)

Mở Terminal và chạy:

curl -fsSL https://vuongnm.github.io/spark/install.sh | bash

Lệnh này tải bản mới nhất trên GitHub, chép Spark vào /Applications rồi mở app. Khi muốn cập nhật thì chạy lại lệnh này. Bạn có thể xem nội dung script trước khi chạy.

Nếu muốn tải bằng trình duyệt thì tải file .dmg rồi kéo Spark vào Applications. Vì Spark chưa có chữ ký của Apple (cần tài khoản Apple Developer, 99 USD một năm) nên lần đầu mở macOS sẽ chặn. Bạn vào Cài đặt hệ thống → Quyền riêng tư & Bảo mật và bấm “Vẫn mở”, hoặc chạy lệnh:

xattr -dr com.apple.quarantine /Applications/Spark.app

Lần đầu mở

Spark tải bộ nhận giọng (khoảng 80 MB) và xin các quyền sau:

  • Micro, để nghe trong lúc bạn giữ phím.
  • Trợ năng (Accessibility), để đọc phím fn và dán chữ.
  • Input Monitoring nếu macOS hỏi. Spark chỉ đọc phím fn, không ghi lại các phím khác.

Nếu nhấn fn mà bảng emoji hiện lên, bạn vào Cài đặt hệ thống → Bàn phím và chọn “Nhấn phím 🌐 để” là Không làm gì.

Để câu viết ra gọn hơn, vào Cài đặt của Spark rồi tải Gemma hoặc dán khoá Claude.

WindowsThử nghiệm · Windows 10, 11

Mở PowerShell và chạy:

irm https://vuongnm.github.io/spark/install.ps1 | iex

Giữ Ctrl bên phải để nói. Bản Windows được build tự động nhưng chưa được thử kỹ trên máy thật, nếu gặp lỗi bạn báo giúp mình trên GitHub nhé.

Tự build

git clone https://github.com/VuongNM/spark.git
cd spark
npm ci
npm run build:native   # phím fn trên macOS, cần Xcode Command Line Tools
npm run dev

Spark viết bằng Electron, React và TypeScript, giấy phép MIT.

Gỡ cài đặt

Chạy lệnh sau để xoá app và dữ liệu:

rm -rf /Applications/Spark.app ~/Library/Application\ Support/Spark

Hỏi đáp

Spark có gửi giọng nói của mình đi đâu không?

Không. Phần nhận giọng chạy hoàn toàn trên máy. Nếu bạn chọn Claude để viết lại thì Spark gửi phần chữ (không gửi âm thanh) tới Anthropic bằng khoá của bạn. Lịch sử chỉ lưu trên máy và xoá được trong app.

Sao macOS chặn file .dmg?

Để macOS mở thẳng, app cần được ký và gửi Apple kiểm tra bằng tài khoản Apple Developer, mất 99 USD một năm. Spark chưa làm bước này. Mã nguồn để công khai nên bạn có thể đọc hoặc tự build.

Sao cài bằng curl lại không bị chặn?

Trình duyệt đánh dấu các file tải từ Internet và macOS chỉ kiểm tra những file có dấu này. curl không đánh dấu, nên bạn nên đọc script trước khi chạy.

Có cần mạng không?

Chỉ cần khi tải mô hình lần đầu và khi dùng Claude. Dùng Gemma thì Spark chạy offline hoàn toàn.

Có mất phí không?

Spark miễn phí. Nếu dùng Claude thì Anthropic tính phí theo khoá API của bạn.

Máy cần cấu hình thế nào?

Mac chip Apple nào cũng chạy được. Gemma dùng thêm khoảng 2 GB RAM, nên nếu máy 8 GB thì dùng Claude sẽ nhẹ hơn.
