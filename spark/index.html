spark: speech to text tiếng việt cho dân Coding

Giữ fn, nói, thả ra là có chữ.

Nói như lúc đi làm, nửa Việt nửa Anh. Spark gõ lại thành câu đàng hoàng rồi dán vào Cursor, VS Code, Terminal, Slack. Khỏi gõ dấu.

$ curl -fsSL https://vuongnm.github.io/spark/install.sh | bash

Dán vào Terminal là xong. Mac chip Apple, 133 MB, miễn phí, mã nguồn mở.

Fix cái bug ở file index.ts rồi commit và push lên branch main nhé.

Chạy thật trên MacBook M1, rút mạng vẫn chạy. Người nói là chị Linh có sẵn trong macOS, tiếng Anh rất Việt. Nghe mất 0,12 giây, gõ lại mất 1 giây.

Cách dùng

  1. Giữ fn rồi nói

    Bong bóng nhỏ hiện dưới đáy màn hình, chữ chạy theo lời bạn.

  2. Thả phím

    Một giây sau, câu đã sửa nằm ngay chỗ con trỏ. App nào cũng được.

  3. Nói dài thì nhấn đúp

    Nhấn fn hai lần là nói rảnh tay, khỏi giữ phím đến mỏi. Nhấn lần nữa để dừng.

Dân code nói chuyện kiểu gì?

Kiểu này: "review giúp anh cái pull request này, deploy lên staging rồi báo nhé". Nửa Việt nửa Anh.

Bộ gõ giọng nói thường nghe câu đó thành "rivo giúp anh cái tun ri quét". Đọc to lên thì đúng. Đọc bằng mắt thì chịu.

Spark nghe bằng hai tai. Tai tiếng Việt chạy ngay trên máy, 5 giây nói đọc xong trong 0,1 giây. Tai tiếng Anh nghe song song để bắt commit, merge, endpoint. Xong thì Gemma (chạy trên máy) hoặc Claude (nếu bạn có khoá) gõ lại thành câu.

Máy nghe "cơ mít", Spark viết commit. Mít để dành ăn.

Đang gõ trong Cursor, VS Code hay Terminal thì Spark giữ nguyên tên file, tên hàm. Nói "index chấm ts" là ra index.ts.

Spark không bịa. Câu gõ lại mà thêm ý hay đổi con số so với lời bạn nói thì Spark vứt, làm lại cách khác.

Có Từ điển để dạy nó tên dự án, tên đồng nghiệp. Tên sếp thì nên dạy sớm.

Âm thanh không rời máy. Dùng Gemma thì rút dây mạng vẫn nói được.

Cài đặt

macOSMac chip Apple (M1 trở lên)

Dán vào Terminal:

curl -fsSL https://vuongnm.github.io/spark/install.sh | bash

Script tải bản mới nhất trên GitHub, chép vào /Applications rồi mở luôn. Muốn cập nhật thì chạy lại. Dân code thì đọc script trước khi chạy nhé, có 40 dòng thôi.

Thích bấm chuột thì tải file .dmg, kéo Spark vào Applications. Spark chưa có chữ ký của Apple (99 USD một năm, mình chưa nỡ), nên lần đầu mở macOS sẽ chặn. Vào Cài đặt hệ thống → Quyền riêng tư & Bảo mật, bấm “Vẫn mở”. Hoặc gõ:

xattr -dr com.apple.quarantine /Applications/Spark.app

Lần đầu mở

Spark tải bộ nhận giọng (khoảng 80 MB) rồi xin vài quyền:

  • Micro: để nghe, chỉ lúc bạn giữ phím.
  • Trợ năng (Accessibility): để đọc phím fn và dán chữ.
  • Input Monitoring, nếu macOS hỏi: Spark chỉ nghe phím fn, phím khác kệ. Không tin thì đọc code.

Nhấn fn mà bảng emoji bật lên? Vào Cài đặt hệ thống → Bàn phím, chọn “Nhấn phím 🌐 để” là Không làm gì.

Muốn câu gọn gàng hơn thì vào Cài đặt của Spark: tải Gemma hoặc dán khoá Claude.

WindowsThử nghiệm · Windows 10, 11

Dán vào PowerShell:

irm https://vuongnm.github.io/spark/install.ps1 | iex

Giữ Ctrl bên phải để nói. Bản Windows build tự động nhưng chưa ai thử kỹ trên máy thật. Lỗi thì báo mình trên GitHub nhé.

Tự build

git clone https://github.com/VuongNM/spark.git
cd spark
npm ci
npm run build:native   # phím fn trên macOS, cần Xcode Command Line Tools
npm run dev

Electron, React, TypeScript. Giấy phép MIT, cứ lấy mà dùng.

Gỡ cài đặt

Không hợp thì gỡ, mình không giận:

rm -rf /Applications/Spark.app ~/Library/Application\ Support/Spark

Hỏi đáp

Spark có gửi giọng mình đi đâu không?

Không. Nhận giọng chạy trên máy. Nếu bạn chọn Claude thì Spark gửi phần chữ (không phải âm thanh) cho Anthropic, bằng khoá của bạn. Lịch sử nằm trên máy, xoá lúc nào cũng được.

Sao macOS chặn file .dmg?

Muốn macOS mở thẳng thì app phải có chữ ký Apple, 99 USD một năm. Spark chưa có. Bù lại mã nguồn mở hết, ai lo thì đọc, ai lo hơn thì tự build.

Sao cài bằng curl lại không bị chặn?

Trình duyệt đóng dấu “tải từ Internet” lên file, macOS chỉ soi những file có dấu đó. curl không đóng dấu. Nên script nào cũng vậy, đọc trước rồi hẵng chạy.

Có cần mạng không?

Chỉ lúc tải mô hình lần đầu, và lúc dùng Claude. Dùng Gemma thì lên máy bay vẫn nói được.

Có mất tiền không?

Spark miễn phí. Dùng Claude thì Anthropic tính tiền vào khoá của bạn.

Máy cần mạnh cỡ nào?

Mac chip Apple nào cũng chạy. Gemma ăn thêm khoảng 2 GB RAM, máy 8 GB thì dùng Claude cho nhẹ.

Thử đi, một dòng thôi.
